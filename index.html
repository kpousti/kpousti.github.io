Route Engine

View code ↗

An A* routing engine in modern C++ over real OpenStreetMap data, about 1.2M nodes and 2.5M edges, with a haversine heuristic for geographic cost.

  • Cache-efficient Compressed Sparse Row graph layout to cut memory use and speed up traversal.
  • Spatial snapping from raw latitude and longitude to the nearest road node.
  • REST API serving GeoJSON routes to a Leaflet map, with payloads about 89% smaller after polyline simplification.
  • C++
  • A*
  • CSR graphs
  • REST
  • GeoJSON

Mini Maps, a weighted shortest-path engine

View code ↗

An adjacency-list graph engine with O(V + E) traversal across weighted and unweighted networks.

  • BFS and binary-heap Dijkstra, O(E log V), with deterministic path reconstruction.
  • Modular components and a reproducible Make build.
